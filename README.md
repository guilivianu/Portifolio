# Portfólio - Guilherme Livianu

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar meus trabalhos, habilidades e serviços como Desenvolvedor Front-end e Assessor de Marketing.

## 🚀 Sobre o Projeto

Este é um site estático, responsivo e moderno, projetado para destacar minha trajetória profissional. Ele contém seções sobre:

- **Sobre Mim:** Um pouco da minha história e experiência.
- **Projetos:** Vitrine dos meus trabalhos recentes (FoodTruck, Academia Star, Landing Pages).
- **Serviços:** O que eu ofereço (Desenvolvimento Web, Mobile App, Web Design).
- **Conhecimentos:** Minhas principais skills técnicas.
- **Contato:** Canais para falar comigo.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica do site.
- **CSS3:** Estilização, layout responsivo e animações.
- **JavaScript:** Interatividade e funcionalidades dinâmicas.
- **FontAwesome:** Ícones vetoriais.
- **Figma/Photoshop:** Ferramentas de design utilizadas no processo criativo.

## 🌐 Como Acessar

Você pode acessar a versão online deste portfólio através do GitHub Pages no seguinte link:

[**Acessar Portfólio Online**](https://guilivianu.github.io/Portifolio/)

_(Nota: Se o link acima não funcionar imediatamente, verifique se o GitHub Pages foi ativado nas configurações do repositório)._

## 📦 Como Rodar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/guilivianu/Portifolio.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd Portifolio
   ```
3. Abra o arquivo `index.html` no seu navegador preferido.
